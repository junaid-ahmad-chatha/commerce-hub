# Commerce Hub visual system

## Theme

Light workspace for a seller working in a bright office during warehouse hours. Restrained palette: warm neutral canvas, charcoal navigation, forest accent for actions. Status colors carry meaning and always have text.

## Typography

System sans, 14px base. 28px page title, 18px section titles, 12px metadata. Tabular numerals for stock and money.

## Layout

232px desktop navigation, fluid main workspace, 32px content padding. Table-first screens, flat summary strips, inline editing panels. Sidebar becomes horizontal navigation on small screens. Tables scroll within their own container.

## Components

Primary forest button; neutral outlined secondary button; full-border warning and error surfaces; compact text badges; consistent labels, focus rings, and disabled/loading states. No decorative animation.

## Tokens

Colors are defined with OKLCH in public/style.css. CSS custom properties govern surface, ink, muted, line, accent, warning, and error. Spacing scale: 4, 8, 12, 16, 24, 32px. Control radius 6px; section radius 9px.
