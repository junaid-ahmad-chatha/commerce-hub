# Deployment status

The previous Heroku owner preview was retired on 11 November 2026. This repository preserves the application source; it does not provide a running hosted service.

For local use, follow the root README. For a new protected single-owner deployment, follow [HEROKU.md](HEROKU.md). Set fresh secrets in the hosting environment and provision your own database. Local credentials, workspace data and private deployment records are not included.

Publishing source on GitHub does not run this Node.js server. GitHub Pages cannot host its server-side API or SQLite database.
